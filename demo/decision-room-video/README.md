# Decision Room: The First Five Minutes

A 42-second square LinkedIn teaser supporting the proposed **Decision Room: Authority Under Pressure** tabletop exercise.

[Watch the teaser](first-five-minutes.mp4)

The video uses on-screen captions, gentle motion, and an original low-volume suspense pulse. It has no spoken narration. The narration draft is in [voiceover.txt](voiceover.txt).

## Rebuild

Requirements: Python 3, Pillow, and FFmpeg.

```bash
python3 build_video.py
```

The script creates scene images and intermediate clips under `scenes/`, then writes `Decision_Room_First_Five_Minutes.mp4`.

## Scope

This is an illustrative discussion teaser. It is not an official exercise brief, a real incident report, or operational cyber-response guidance. It does not prescribe containment actions.
